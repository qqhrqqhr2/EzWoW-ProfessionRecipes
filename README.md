# EzWoW-ProfessionRecipes

**Profession recipe browser | 전문기술 제조법 도감**

> WoW Forever addon · Interface 16001

## English

Browse profession recipes, ingredients, trainers, vendors, and unlearned recipes with map integration.

### Features
- Built for the WoW Forever client.
- Independent addon; optional integration with other EzWoW addons where supported.
- In-game commands and settings vary by addon; refer to the full documentation shipped with the addon.

### Installation
1. Obtain the addon source/package for this repository.
2. Place the `EzWoW-ProfessionRecipes` folder inside `World of Warcraft/_retail_/Interface/AddOns/` or your client's applicable `Interface/AddOns/` folder.
3. Restart the game and enable the addon from the addon list.

### Documentation
See `CHANGELOG.md` for changes and `LICENSE` / `LICENSE.txt` for licensing when they are included in the source upload. Game-client compatibility has not been independently verified.

## 한국어

전문기술 제조법·재료·습득처 검색, 배우지 않은 제조법 및 지도 연동 기능을 제공하는 WoW Forever 애드온입니다.

### 주요 특징
- WoW Forever 클라이언트 대응 (Interface 16001).
- 다른 EzWoW 애드온과 독립적으로 설치할 수 있으며, 일부 기능은 선택적으로 연동됩니다.

### 설치 방법
1. 해당 저장소의 애드온 배포 파일을 준비합니다.
2. `EzWoW-ProfessionRecipes` 폴더를 게임 클라이언트의 `Interface/AddOns/`에 복사합니다.
3. 게임을 다시 시작하고 애드온 목록에서 활성화합니다.
